# AI
Repository with projects and assignments from my Artificial Intelligence course, covering fundamental AI techniques and algorithmic implementations.

## Overview
This repository contains a series of lab assignments that explore core concepts in Artificial Intelligence and Machine Learning. The work progresses from foundational data manipulation and visualization to building and training neural networks.

## What This Repository Covers
- **Data Preprocessing** : Feature scaling, normalization, encoding categorical variables and preparing datasets for ML pipelines
- **Classical Machine Learning** : Linear regression, regularization techniques (L1, L2, Elastic Net) and Decision Trees with model evaluation and hyperparameter tuning
- **Neural Networks & Deep Learning** : Activation functions, automatic differentiation, perceptrons, multilayer networks and classification models
- **Key Libraries** : NumPy, Pandas, Matplotlib, Seaborn, scikit-learn and PyTorch
- 
## What You'll Learn
By exploring these labs, you'll gain hands-on experience with:
- Preparing and transforming real-world datasets for machine learning
- Building regression and classification models from scratch and with established libraries
- Understanding how activation functions and network architecture affect model behavior
- Implementing the full ML workflow: data preparation, model definition, training, evaluation and tuning
- Using PyTorch tensors, autograd and `nn` modules to construct neural networks
